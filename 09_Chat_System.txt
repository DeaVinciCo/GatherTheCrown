=== CHAT SYSTEM ===

IN-GAME CHAT:
- Hidden by default
- Press Enter to slide in at bottom-right
- Shows last 8 lines
- Auto-hides after 5 seconds of inactivity
- Nearly transparent background (10–15% opacity)
- Mouse wheel scroll for history

LOBBY CHAT:
- Always visible version
- Same features but doesn't auto-hide

CHAT COLORS:
- Main Name Color: Blue (70, 120, 220) - default for all names
- Faction Color: Indigo (88, 63, 164) - when player is in faction
- System: Gold (212, 175, 55)
- Mod: Red (184, 64, 64)
- PM: Purple (162, 120, 200)
- Team: Blue (78, 121, 181)
- Emote: Light gray (200, 200, 200)

ELEMENT COLORS (for badges):
- Fire: (255, 120, 60)
- Water: (90, 160, 255)
- Earth: (120, 180, 120)
- Storm: (180, 180, 255)
- Light: (255, 255, 210)
- Shadow: (170, 120, 200)
- Arcane: (190, 170, 255)

SLASH COMMANDS:
- /p <name> <message> or /w <name> <message> - Private message
- /mod <message> - Alert moderators nearby
- /team <message> - Team chat
- /me <emote> - Emote action
- /help - Show command list

CHAT FEATURES:
- Timestamps [HH:MM]
- Channel tags [TEAM], [PM], [MOD], [SYS]
- Element badges (icons or colored sigils)
- Nameplate with tiny crown icon
- Text wrapping for long messages
- Parchment-style background with bronze borders

MESSAGE FORMAT:
[HH:MM] [CHANNEL] [badge] Name 👑: message text
