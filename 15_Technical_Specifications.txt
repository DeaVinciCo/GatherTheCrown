=== TECHNICAL SPECIFICATIONS ===

=== ENGINE & PLATFORM ===

PRIMARY ENGINE: Python with Pygame
- Flat 2D rendering
- Cross-platform (Windows, macOS, Linux)
- Lightweight and accessible

ALTERNATIVE 3D OPTION (Future):
- Ursina Engine (Python-based 3D)
- Panda3D (Python 3D engine)
- Keep 2D UI overlays even in 3D mode

=== RESOLUTION & DISPLAY ===

TARGET RESOLUTIONS:
- Primary: 1280x720 (HD)
- Full HD: 1920x1080
- Scalable UI (75%–150%)
- Windowed and fullscreen modes
- Aspect ratio: 16:9 (primary), 16:10 (supported)

FRAME RATE:
- Target: 60 FPS
- Minimum: 30 FPS
- V-Sync option

=== ASSET SPECIFICATIONS ===

SPRITES & TILES:
- Base tile size: 64x64 pixels
- HD variant: 128x128 pixels
- Character sprites: 96x96 to 128x128
- Boss sprites: 256x256 to 512x512
- Format: PNG with transparency
- Color depth: 32-bit RGBA

ANIMATIONS:
- Frame counts: 4f (idle), 6–8f (walk/attack), 8–12f (complex)
- Frame rate: 12–15 FPS for animations
- Sprite sheets with consistent frame sizes
- Naming: asset_name_f08.png (8 frames)

UI ELEMENTS:
- Icons: 24x24, 32x32, 64x64 pixels
- Buttons: 9-slice scalable
- Panels: 9-slice parchment backgrounds
- Fonts: TTF format, multiple sizes

AUDIO:
- Music: OGG format, 128-192 kbps, stereo
- SFX: OGG or WAV, 44.1kHz, mono or stereo
- Ambience: OGG, loopable, 96-128 kbps
- Voice: OGG, 64-96 kbps, mono

=== PERFORMANCE TARGETS ===

MEMORY:
- RAM usage: < 512 MB (2D mode)
- VRAM usage: < 256 MB
- Asset streaming for large worlds

LOADING TIMES:
- Initial load: < 10 seconds
- Scene transitions: < 2 seconds
- Asset streaming: seamless (no visible loading)

OPTIMIZATION:
- Sprite batching for multiple entities
- Culling for off-screen objects
- LOD (Level of Detail) for distant objects
- Texture atlases to reduce draw calls
- Object pooling for frequently spawned entities
