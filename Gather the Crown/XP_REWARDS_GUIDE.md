# 💫 XP Rewards System Guide

## 🎯 Overview

Players earn XP not just from combat and quests, but also from taking care of themselves and their creat! Every preparation action rewards XP, encouraging healthy gameplay habits.

## ✨ Why Reward Preparation?

1. **Encourages Self-Care** - Players learn to maintain stats
2. **Rewards Thoroughness** - Being prepared pays off
3. **Builds Creat Bond** - Caring for companion gives XP
4. **Prevents Rushing** - Taking time to prepare is valuable
5. **Tracks Player Choices** - Analytics show what players do

## 💰 XP Breakdown

### Individual Actions

| Action | Base XP | Notes |
|--------|---------|-------|
| Eat Food | 10 XP | +50% for premium/stew |
| Drink Water | 5 XP | Basic hydration |

| Feed Creat | 15 XP | +100% for premium food |
| Pet Creat | 10 XP | Quick affection |
| Play with Creat | 20-60 XP | Scales with time (max 3x) |
| Craft Item | 30 XP | +200% legendary, +100% rare |

### Interactive Cutscene Actions

XP is **dynamically calculated** based on:
- Total number of actions in cutscene
- Whether action is required or optional
- Cutscene type (morning, quest prep, boss prep, etc.)

#### Formula:
```
Base XP = (Total Cutscene XP) / (Number of Actions)
If Required: Base XP × 1.5
If Restores Stats: +5 XP
If Creat Care: +10 XP
```

## 🔥 Daily Streak System

### How It Works
- Complete morning routine each day
- Streak increases by 1
- Earn bonus XP: +25 per day
- Max streak bonus: +500 XP (20 days)

### Streak Rewards
```
Day 1: 50 + 25 = 75 XP
Day 2: 50 + 50 = 100 XP
Day 3: 50 + 75 = 125 XP
Day 5: 50 + 125 = 175 XP
Day 10: 50 + 250 = 300 XP
Day 20: 50 + 500 = 550 XP (max)
```

### Streak Breaks
- Skip morning routine → Streak resets to 0
- Must start over from Day 1
- Encourages daily play

## 🎯 Balancing Notes

### XP vs Quest Rewards
- Quest completion: ~500 XP
- Full day prep: ~1,000 XP
- Prep is ~50% of daily XP
- Encourages balanced gameplay

### Time Investment
- Morning routine: 2 min = ~150 XP (75 XP/min)
- Quest: 15 min = ~500 XP (33 XP/min)
- Prep is more XP-efficient per minute!

### Progression Impact
- Level 1→2: 1,000 XP needed
- With prep: ~1 day
- Without prep: ~2 days
- Prep speeds progression by 50%!
