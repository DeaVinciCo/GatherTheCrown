# Mode Structure And Ranking

Created: April 2026
Owner: Game Modes + Progression Systems

## Mode Pillars

1. Story Mode
2. Racing + Mini Games
3. PvP + PvE + Battle Royale (optional phase)

This document defines what is leaderboard-able, what is ranked, and where factions fit.

## 1) Story Mode

Primary purpose:
- World progression, side quests, restoration arcs, and kingdom handback narrative.

Includes:
- Main kingdom arcs
- Side quests
- Castle floor clears
- Restoration and owner handback

Leaderboard status:
- Not globally ranked by default.
- Optional local boards only (fastest castle clear, completion score).

Ranked status:
- Unranked by default.
- Story should focus on progression, not ladder pressure.

## 1A) Side Quests Inside Story Mode

Side quest categories:
- Finder quests (town item recovery)
- Clearance quests (clear infested/broken spaces)
- Restoration quests (deliver and rebuild)

Leaderboard-able:
- Yes, optional category boards:
  - Most successful handbacks
  - Fastest restoration completion
  - Highest side-quest streak

Ranked options:
- Default: Unranked
- Optional seasonal rank track: Side Quest Championship pass

Recommended:
- Keep rewards meaningful without forcing competitive play.

## 2) Racing + Mini Games

Primary purpose:
- High replay loops and skill expression.

### Racing

Leaderboard-able:
- Yes (global, regional, friends)

Ranked status:
- Ranked queue: Yes
- Unranked queue: Yes

Championships:
- Weekly qualifiers
- Monthly finals
- Seasonal title rewards

Ranking model:
- Placement points + consistency bonus
- DNF penalty only in ranked

### Mini Games

Leaderboard-able:
- Yes (mode-specific scoreboards)

Ranked status:
- Ranked variants for selected mini games
- Casual unranked for all mini games

Championships:
- Rotating mini-game cups
- Event weekends with boosted rewards

## 3) PvP + PvE + Battle Royale

### PvP

Leaderboard-able:
- Yes (duel rating, team rating, win streak)

Ranked status:
- Ranked and unranked both supported

Recommended ranked formats:
- 1v1 duel
- 2v2 skirmish

### PvE

Leaderboard-able:
- Yes (boss clear times, raid score, survival depth)

Ranked status:
- Two tracks:
  - Competitive PvE ladders (ranked)
  - Adventure PvE runs (unranked)

Recommended:
- Keep some PvE content non-ranked so cooperative play stays welcoming.

### Battle Royale

Leaderboard-able:
- Yes, if launched

Ranked status:
- Ranked and unranked when mode is stable

Scope decision:
- Do not place BR on current critical path.
- Launch only after core Story + Side Quest + Racing/PvP loops are polished.
- Keep BR economy separate enough to avoid destabilizing story progression rewards.

## Faction Layer (For PvP/PvE/Optional BR)

Faction concept:
- Players align with one faction path during a season (or remain neutral in unranked).

Faction features:
- Faction points from ranked matches and PvE objectives
- Weekly faction objectives
- Territory or influence scoreboards
- Faction rewards at season end

Ranked and non-ranked usage:
- Ranked: faction points enabled
- Unranked: optional faction contribution toggle

Safety rule:
- No faction lockout for Story Mode progression.

## Ranked vs Unranked Rules

Ranked should include:
- Skill rating changes
- Matchmaking constraints
- Seasonal rewards and titles
- Clear anti-abandon penalties

Unranked should include:
- Fast queue
- Looser matchmaking
- Lower pressure progression
- Practice and experimentation spaces

## Recommended Launch Sequence

Phase A (Now):
- Story Mode + Side Quests fully playable
- Racing and Mini Games with leaderboards (unranked first)

Phase B:
- Ranked Racing and selected Ranked Mini Games
- Ranked PvP (1v1 first)
- PvE score ladders

Phase C:
- Faction seasonal system across ranked modes
- Optional Battle Royale pilot season

## Simple UI Taxonomy

Main menu mode tiles:
- Story Mode
- Side Quests
- Racing
- Mini Games
- PvP
- PvE
- Battle Royale (locked until release)

Each tile should show:
- Ranked badge: ON/OFF
- Leaderboard icon: ON/OFF
- Faction icon: ON/OFF

## One-line Product Framing

Story Mode builds the world; championships and ladders test mastery.
