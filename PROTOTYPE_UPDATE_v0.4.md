## How to Play

1. **Server is running at:** http://localhost:3001
2. Open your browser and go to that URL
3. Choose a game mode from the menu
4. Use the controls (see below)

---

## Controls

### Race Mode 🏁
- **W/↑** = Forward
- **S/↓** = Backward
- **A/←** = Turn Left
- **D/→** = Turn Right
- **Space** = Jump
- **Shift** = Boost

### Combat Mode ⚔️
- **WASD/Arrows** = Move
- **Space** = Attack
- **Shift** = Dodge
