# 🏰 Gather The Crown: Creats & Foes - Game Package

## 🎮 What's Included

This package contains the complete game experience:

1. **Epic Title Screen** - Animated launch screen with mystical effects
2. **User Authentication** - Login and registration system
3. **Character Creation** - Customize your hero's name, element, and weapon
4. **Complete Medieval Game** - Full adventure with all features

## 🚀 Quick Start

### Windows Users:
1. Double-click `PLAY_GAME.bat`
2. Follow the on-screen instructions

### Mac/Linux Users:
1. Open terminal in this folder
2. Run: `python main_launcher.py`

## 📋 System Requirements

- Python 3.7+ (will auto-install pygame if needed)
- 100MB free space
- Any modern computer

## 🎯 Game Flow

1. **Launch Screen** → Click "Begin Adventure" or "Continue Adventure"
2. **Login/Register** → Create account or sign in
3. **Character Creation** → Name your hero and choose abilities
4. **Medieval Adventure** → Explore, battle, and collect treasures!

## 🎮 Game Controls

- **WASD/Arrow Keys**: Move character
- **Shift**: Toggle chat window
- **I**: Open/close inventory
- **M**: Open/close world map
- **Mouse**: Hover for tooltips, click map to travel
- **ESC**: Close panels or exit

## 🏰 Game Features

- Epic medieval world with detailed graphics
- Multiple creature types (Orcs, Goblins, Skeletons, Bandits, Bats)
- Realistic treasure system with rarity effects
- Interactive map for fast travel
- Character progression and inventory management
- Real-time combat with animations

## 🔧 Troubleshooting

**Game won't start?**
- Make sure Python is installed
- Try: `pip install pygame`
- Run: `python --version` to check Python

**Need help?**
- Check that all files are in the same folder
- Restart your computer and try again
- Make sure you have internet for first-time pygame install
