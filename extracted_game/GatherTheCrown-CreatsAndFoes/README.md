# 🏰 Gather The Crown: Creats & Foes

**An epic medieval adventure game where you forge bonds with mystical creatures and gather legendary Crown Shards to restore balance to the realm.**

## 🎮 Game Features

- **Epic Medieval Adventure**: Explore a rich fantasy world filled with creatures and treasures
- **Creature Companions**: Bond with mystical Creats and battle fierce foes
- **Character Creation**: Choose your elemental affinity and preferred weapon
- **Real-time Combat**: Engage in dynamic battles with various enemy types
- **Treasure Hunting**: Discover rare items and crown shards throughout the realm
- **Interactive World**: Use the map system to travel quickly between locations
- **Inventory Management**: Collect and manage your growing arsenal of items

## 🚀 Quick Start

### Option 1: Simple Launch (Requires Python)
1. Make sure you have Python 3.7+ installed
2. Install pygame: `pip install pygame`
3. Run the game: `python main_launcher.py`

### Option 2: Easy Launch (Windows)
1. Double-click `launch_game.bat`
2. Follow the on-screen instructions

## 🎯 How to Play

### First Time Players
1. **Launch the Game** - Run `main_launcher.py` or `launch_game.bat`
2. **Create Account** - Register with username, email, and password
3. **Create Character** - Choose your rider's name, element, and weapon
4. **Enter the Realm** - Begin your adventure!

### Returning Players
1. **Launch the Game** - The launcher will detect your existing account
2. **Login** - Enter your credentials
3. **Continue Adventure** - Resume where you left off

## 🎮 Controls

- **WASD / Arrow Keys**: Move your character
- **Shift**: Toggle chat window
- **I**: Open/close inventory
- **M**: Open/close world map
- **Mouse**: Hover for tooltips, click map to travel
- **ESC**: Close panels or exit game

## 📦 Installation Requirements

The game requires Python and pygame. If you don't have them:

### Windows
```bash
# Install Python from python.org, then:
pip install pygame
```

### macOS
```bash
# Install Python via Homebrew, then:
pip3 install pygame
```

### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install python3 python3-pip
pip3 install pygame
```

## 🐛 Troubleshooting

### Game Won't Start
- Ensure Python 3.7+ is installed
- Install pygame: `pip install pygame`
- Try running: `python --version` to check Python installation

### Performance Issues
- Close other applications to free up memory
- Try running in windowed mode
- Update your graphics drivers

### Login/Save Issues
- Check that the game folder has write permissions
- Ensure `users.json` and `user_data.json` aren't corrupted
- Delete save files to start fresh if needed
